Three concentric layers, each a separate Terraform workspace with its own state:
- `bootstrap/00-org-structure` — creates the Resource Directory and folder/account hierarchy by calling vendored LZA modules `modules/lza/components/resource-structure/folders` and `accounts`; `01-cicd-foundation` provisions OSS (KMS-encrypted, versioned) + Tablestore lock table, an IMS OIDC provider for GitHub, and two hub roles (`GitHubActionsPlanRole`, `GitHubActionsApplyRole`) scoped to PR vs. `environment:production`; `02-spoke-bootstrap` creates per-member `SpokePlanRole`/`SpokeApplyRole`.
- `stacks/<number>-<name>/` — one workspace per spoke account; each stack declares `providers.tf`/`variables.tf`/`main.tf` and is driven by the matrix in `.github/workflows/stacks.yml`, which maps a stack name to an `account_key` resolved from `SPOKE_ACCOUNT_IDS_JSON`. The `20-network-cen` stack demonstrates inline resource definitions while commenting out the vendored module path as the production pattern.
- `modules/lza/` — git submodule of `aliyun/landing-zone-accelerator-on-alibaba-cloud` pinned to `main`, split into reusable `components/*` (account-factory, guardrails, identity/cloudsso, log-archive, network, resource-structure, security) and leaf `modules/*` (vpc, oss-bucket, sls-project, kms-instance, etc.).
- `.github/workflows/` — CI orchestration: `terraform-reusable.yml` is a `workflow_call` entry point that performs checkout → OIDC credential setup (`aliyun/configure-aliyun-credentials-action`) → `setup-terraform@v3` → init/plan/apply, posting plan diffs as PR comments; the four bootstrap workflows call it per directory, while `stacks.yml` runs a parallel matrix over all stacks, gating apply on the `production` GitHub environment.

Dependency direction is strictly one-way: workflows invoke bootstrap phases in order, then drive stacks; stacks consume only `modules/lza` components — nothing inside `modules/lza` references bootstrap or stacks. State lives in OSS with Tablestore locking, and the credential chain is GitHub OIDC token → Hub Role (CICD) → Spoke Role (member account) → Alicloud provider.
